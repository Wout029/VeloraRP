Velora RP website

Structuur:
- index.html
- pages/: community, personen, about/jobs, contact, changelog
- css/: main, community, animations
- js/: navigation, main, community, jobs, team, trailer, server-status, changelog
- assets/images/: logo, people, backgrounds
- data/changelog.json: handmatige server- en website-updates
- api/server-status.php: optionele proxy voor live FiveM-status
- integrations/discord-changelog-bot/: optionele toekomstige Discord-automatisering

Live serverstatus:
De teller probeert publieke Cfx/FiveM-serverinformatie te gebruiken. Wanneer je hosting directe serverrequests blokkeert, moet de PHP-proxy bereikbaar zijn of moet een publiek server-endpoint worden geconfigureerd.
